# Demo screenshots

Các ảnh trong thư mục này được tạo từ app local bằng Playwright để dùng trong báo cáo và slide:

- `01-landing.png`: trang giới thiệu và nhận diện thương hiệu.
- `02-upload-wizard.png`: luồng tải lên, mã hoá và cấu hình quyền.
- `03-dashboard-inbox.png`: dashboard quản lý tài liệu, token và trạng thái.
- `04-download-viewer.png`: màn nhận token và vùng Viewer bảo vệ.

Khi chạy demo thật với 3 ví A/B/C, nên chụp bổ sung màn hình phê duyệt A+B cấp token cho C nếu cần minh hoạ sâu hơn.
